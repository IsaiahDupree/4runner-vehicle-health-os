# KiCad ESP32-S3 library assets

The `ESP32-S3-WROOM-1.kicad_mod` footprint and `ESP32-S3-WROOM-1.step` model
come from the KiCad 10 library. The project-local footprint uses the native
land pattern and keepout, omits the optional 0.2 mm thermal pad drill array,
puts the overhanging silkscreen lines on the fabrication layer, and points
to the bundled STEP model. The STEP file is the original KiCad library asset.
